SCRATCH ADVENTURE CODE REALM — GitHub Pages

1. Upload every file in this folder to the root of a GitHub repository.
2. index.html is the entry point and is a copy of login.html.
3. Do NOT upload Code(1).gs to GitHub Pages. Keep the Apps Script code in Google Apps Script.
4. The web app API URL is already configured in the HTML/JS files.
5. Enable GitHub Pages from Settings > Pages > Deploy from branch > main > /(root).
6. Open the generated Pages URL. Students can log in and submit mission scores online.
7. Google Sheets remains the source of truth for scores.
